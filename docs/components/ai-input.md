# Ai Input

用来写给 AI 的内容，也可以附上文件。宽度跟着父级走：不到 560px 时文字在上、按钮在下，最窄 374px，最宽 832px。

## 引入

```js
import 'genv4/ai-input/ai-input.js';
```

## 示例

没有文字时发送按钮不可点。点左侧加号可以上传文件。

| `value` | `value` | `string` | `''` | 输入框里的文字。只有空格时视为没有文字。 |

| `files` |  | `readonly File[]` | `undefined` | 已选择的文件。只读，选择或移除文件时更新。 |
