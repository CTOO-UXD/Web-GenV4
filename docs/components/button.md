# 按钮

按钮用来触发一个操作，例如提交表单、确认，或打开一个链接。

## 引入

按要使用的外观分别引入。一个操作区域里只放一个实心按钮作为主操作。

| 标签 | 何时使用 |
| --- | --- |
| `<md-filled-button>` | 主操作 |
| `<md-filled-tonal-button>` | 比描边更需要强调的次主操作 |
| `<md-elevated-button>` | 需要和有图案的背景分开时 |
| `<md-outlined-button>` | 次操作 |
| `<md-text-button>` | 最低优先级的操作 |

```js
import 'genv4/button/filled-button.js';
import 'genv4/button/filled-tonal-button.js';
import 'genv4/button/elevated-button.js';
import 'genv4/button/outlined-button.js';
import 'genv4/button/text-button.js';
```

## API

五种按钮的属性相同，下表适用于 `<md-filled-button>`、`<md-filled-tonal-button>`、`<md-elevated-button>`、`<md-outlined-button>`、`<md-text-button>`。

### 属性

<!-- mdformat off(autogenerated might break rendering in catalog) -->

| 属性 | HTML 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `softDisabled` | `soft-disabled` | `boolean` | `false` | 禁用后仍可聚焦。需要让不可用的按钮仍能被键盘发现时使用。 |
| `href` | `href` | `string` | `''` | 设置后按钮变成链接，指向该 URL。 |
| `download` | `download` | `string` | `''` | 作为链接时，下载文件使用的文件名。不设置则由浏览器决定。 |
| `target` | `target` | `string` | `''` | 作为链接时，在何处打开 href。常用 `_blank` 在新标签页打开。 |
| `rel` | `rel` | `string` | `''` | 作为链接时，写到内部 a 元素的 rel。 |
| `referrerPolicy` | `referrerpolicy` | `string` | `''` | 作为链接时，写到内部 a 元素的 referrerpolicy。 |
| `trailingIcon` | `trailing-icon` | `boolean` | `false` | 把图标放到文字后面。链接按钮不能用末尾图标。 |
| `hasIcon` | `has-icon` | `boolean` | `false` | 是否显示图标。 |
| `name` | `name` | `string` | `undefined` | The HTML name to use in form submission. |
| `disabled` | `disabled` | `boolean` | `undefined` | Whether or not the element is disabled. |
| `type` | `type` | `string` | `'submit'` | A string indicating the form submission behavior of the element.<br>- submit: The element submits the form. This is the default value if the attribute is not specified, or if it is dynamically changed to an empty or invalid value. - reset: The element resets the form. - button: The element does nothing. |
| `value` | `value` | `string` | `''` | The value of the button. When combined with a `name`, the submitting button's name/value will be added to the form. |
| `form` |  | `HTMLFormElement` | `undefined` | The associated form element with which this element's value will submit. |
| `labels` |  | `NodeList` | `undefined` | The labels this element is associated with. |

### 插槽

五种按钮共用这些插槽。

| 名称 | 说明 |
| --- | --- |
| 默认 | 按钮文字 |
| `icon` | 图标。显示时加上 `has-icon`。`trailing-icon` 把图标放到文字后面。链接按钮不能用末尾图标。 |
