# 图标按钮

图标按钮用来放一个图标操作，例如打开菜单、切换状态，或跳转到链接。

## 引入

四种外观的属性相同。

| 标签 | 何时使用 |
| --- | --- |
| `<md-icon-button>` | 无底色，优先级最低 |
| `<md-filled-icon-button>` | 实心 |
| `<md-filled-tonal-icon-button>` | 浅色实心 |
| `<md-outlined-icon-button>` | 描边 |

```js
import 'genv4/iconbutton/icon-button.js';
import 'genv4/iconbutton/filled-icon-button.js';
import 'genv4/iconbutton/filled-tonal-icon-button.js';
import 'genv4/iconbutton/outlined-icon-button.js';
```

### 切换

加上 `toggle` 后可以在两个图标之间切换。未选中用默认插槽，选中用 `slot="selected"`。

<div class="figure-wrapper">
  <figure>
    <md-icon-button toggle aria-label="未选中" aria-label-selected="已选中">
      <md-icon>close</md-icon>
      <md-icon slot="selected">check</md-icon>
    </md-icon-button>
  </figure>
</div>

```html
<md-icon-button toggle aria-label="未选中" aria-label-selected="已选中">
  <md-icon>close</md-icon>
  <md-icon slot="selected">check</md-icon>
</md-icon-button>
```

## API

四种图标按钮的属性相同，下表适用于 `<md-icon-button>`、`<md-filled-icon-button>`、`<md-filled-tonal-icon-button>`、`<md-outlined-icon-button>`。

| 属性 | HTML 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `softDisabled` | `soft-disabled` | `boolean` | `false` | 禁用后仍可聚焦。需要让不可用的按钮仍能被键盘发现时使用。 |
| `flipIconInRtl` | `flip-icon-in-rtl` | `boolean` | `false` | 从右向左排版时翻转图标。 |
| `href` | `href` | `string` | `''` | 设置后按钮变成链接，指向该 URL。 |
| `download` | `download` | `string` | `''` | 作为链接时，下载文件使用的文件名。不设置则由浏览器决定。 |
| `target` | `target` | `string` | `''` | 作为链接时，在何处打开 href。常用 `_blank` 在新标签页打开。 |
| `rel` | `rel` | `string` | `''` | 作为链接时，写到内部 a 元素的 rel。 |
| `referrerPolicy` | `referrerpolicy` | `string` | `''` | 作为链接时，写到内部 a 元素的 referrerpolicy。 |
| `ariaLabelSelected` | `aria-label-selected` | `string` | `''` | 可切换且已选中时使用的无障碍名称。 |

| `selected` | `selected` | `boolean` | `false` | 是否选中。未选中显示默认图标，选中显示 `slot="selected"` 里的图标。没有选中图标时继续显示默认图标。 |

### 插槽

四种图标按钮共用这些插槽。

| 名称 | 说明 |
| --- | --- |
| 默认 | 未选中时的图标 |
| `selected` | 选中时的图标。不写就继续用默认插槽 |
