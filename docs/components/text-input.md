# 文本输入

用来填写一行或一段文字。三种外观共用同一套属性和颜色。

## 引入

按要使用的外观分别引入。

| 标签 | 何时使用 |
| --- | --- |
| `<md-text-input>` | 一行短文字，例如名字、邮箱 |
| `<md-action-input>` | 一行文字，并在框内发送 |
| `<md-text-area>` | 一段长短不定的文字，例如评论、备注 |

```js
import 'genv4/text-input/text-input.js';
import 'genv4/text-input/action-input.js';
import 'genv4/text-input/text-area.js';
```
