# 搜索栏

搜索栏用来输入关键字并提交。结果由页面放进 `results` 插槽，展开和收起也由页面控制。

## 引入

结果行用 `<md-gen-menu-item>`。结果里的方向键和 Enter 由页面或菜单处理，搜索栏只负责输入和提交。`disabled` 时输入、清空、麦克风和提交都不可用。没有文字时提交按钮禁用。

| 标签 | 何时使用 |
| --- | --- |
| `<md-search-bar>` | 输入关键字并提交 |
| `<md-gen-menu-item>` | 一行结果 |

```js
import 'genv4/search-bar/search-bar.js';
import 'genv4/gen-menu/gen-menu-item.js';
```

## 示例

宽窄由组件自己的宽度决定，小于 560px 是窄屏。`open` 和输入框里有没有文字无关。结果最大高度用 `--md-search-bar-results-max-height` 设置。
